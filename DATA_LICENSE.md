# Data attribution

Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C5BW33
Dataset page: https://archive.ics.uci.edu/dataset/352/online+retail
License: Creative Commons Attribution 4.0 International (CC BY 4.0).
https://creativecommons.org/licenses/by/4.0/

The original data covers a UK-based non-store retailer in 2010–2011. This project transforms it by removing exact duplicate records, quarantining invalid financial rows, normalizing identifiers, rounding unit prices to pennies, aggregating revenue/cohorts, and producing customer features and predictive scores. The author of the original dataset does not endorse this project.

The original workbook is downloaded from UCI and is not checked into this repository. Derived CSV data, analysis, and model evidence are provided with this attribution under CC BY 4.0. The MIT license applies to original project code, not to the source dataset. Dataset customer identifiers are pseudonymous; no private resume or employer data is included.
